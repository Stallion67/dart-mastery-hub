# dart-mastery-hub
This Project Documents Implementations of Dart Code.


## 🎯 Project Modules

⚡ 1. Dart Crash Course (/Dart_Crash_Course)
A beginner-to-intermediate hands-on module structured to get you up and running with core language syntax quickly.

Key Topics Covered:

Fundamental syntax, variables, and type inference

Control structures and execution flow

Function declaration patterns and scope

Manipulating key data collections

Object-Oriented Programming (OOP) fundamentals

📚 2. Dart Pedia (/Dart_Pedia)
An advanced reference module acting as a topic-by-topic encyclopedia for intermediate to senior Dart usage.

Key Topics Covered:

Asynchronous execution model (Futures, Streams, Isolates)

Object-oriented design patterns tailored for Dart

Complex generics, variance, and type aliases (typedef)

Advanced null safety mechanics and soundness
